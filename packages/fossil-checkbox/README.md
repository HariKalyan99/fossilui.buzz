# @fossilui/checkbox

Animated checkbox components from Fossil UI. Live docs: https://fossilui.buzz/components/toggles

## Install

```bash
npm install @fossilui/checkbox lucide-react
```

### CSS

```css
@import "tailwindcss";

@source "../node_modules/@fossilui/checkbox/dist";
```

## Notes

- Same components as `@fossilui/react` — install one or the other, not both.
- Respects `prefers-reduced-motion`.
