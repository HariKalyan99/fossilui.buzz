# @fossilui/switch

Animated switch components from Fossil UI. Live docs: https://fossilui.buzz/components/toggles

## Install

```bash
npm install @fossilui/switch
```

### CSS

```css
@import "tailwindcss";

@source "../node_modules/@fossilui/switch/dist";
```

## Notes

- Same components as `@fossilui/react` — install one or the other, not both.
- Respects `prefers-reduced-motion`.
