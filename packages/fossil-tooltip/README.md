# @fossilui/tooltip

Animated tooltips from [Fossil UI](https://fossilui.buzz). Live docs: https://fossilui.buzz/components/tooltip

## Install

```bash
npm install @fossilui/tooltip
```

### CSS

```css
@source "../node_modules/@fossilui/tooltip/dist";
```

## Motions

`fade`, `scale`, `slide`, `rise`, `blur`, `pop`, `grow`, `lift`

Named exports: `FadeTooltip`, `ScaleTooltip`, `SlideTooltip`, `RiseTooltip`, `BlurTooltip`, `PopTooltip`, `GrowTooltip`, `LiftTooltip`.
