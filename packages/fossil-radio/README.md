# @fossilui/radio

Animated radio group components from Fossil UI. Live docs: https://fossilui.buzz/components/toggles

## Install

```bash
npm install @fossilui/radio
```

### CSS

```css
@import "tailwindcss";

@source "../node_modules/@fossilui/radio/dist";
```

## Notes

- Same components as `@fossilui/react` — install one or the other, not both.
- Respects `prefers-reduced-motion`.
