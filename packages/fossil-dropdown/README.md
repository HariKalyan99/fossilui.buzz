# @fossilui/dropdown

Animated dropdown menus from [Fossil UI](https://fossilui.buzz). Live docs: https://fossilui.buzz/components/dropdown

## Install

```bash
npm install @fossilui/dropdown lucide-react
```

### CSS

```css
@source "../node_modules/@fossilui/dropdown/dist";
```

## Motions

`fade`, `scale`, `slideDown`, `slideUp`, `blur`, `pop`, `rise`, `wipe`

Named exports: `FadeDropdown`, `ScaleDropdown`, `SlideDownDropdown`, `SlideUpDropdown`, `BlurDropdown`, `PopDropdown`, `RiseDropdown`, `WipeDropdown`.
